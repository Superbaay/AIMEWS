Arquitectura

Tres componentes conectados en tiempo real.

El dron, la infraestructura de comunicación y el sitio web intercambian telemetría y comandos de forma bidireccional.

01Hardware

Dron

Controla estabilidad, dirección y velocidad mediante PID. Recorre los waypoints de la misión y regresa a su origen.

  • Microcontrolador ESP32-S3
  • Acelerómetro y giroscopio
  • Barómetro de altitud absoluta
  • LiDAR TF Mini Plus
  • Magnetómetro y GPS
02Comunicación

Infraestructura

La API almacena y procesa la información, autentica usuarios por rol y transmite comandos entre el sitio y el dron.

  • API en FastAPI
  • Red móvil propia
  • HTTPS y WebSockets
  • Tokens JWT y contraseñas cifradas
  • Base de datos MongoDB
03Visualización

Control y monitoreo

Desde el sitio web se inician las misiones, se consulta el estado de los puntos críticos y se controla el dron.

  • Interfaz de control
  • Telemetría en tiempo real
  • Video desde el dron
  • Control manual remoto
  • Verificación de usuarios
Funcionamiento

De la misión de referencia a la alerta.

  1. 01

    Misión de referencia

    El dron recorre los puntos críticos y registra la distancia ideal al suelo en cada waypoint.

  2. 02

    Evento climático

    Después de lluvias torrenciales, tormentas o huracanes se programa una segunda misión.

  3. 03

    Medición y fotografía

    Dos servomotores mantienen el LiDAR perpendicular al suelo; la lectura se contrasta con el barómetro y se envía una fotografía del punto.

  4. 04

    Alerta

    La API compara ambas misiones y notifica a las autoridades correspondientes.
